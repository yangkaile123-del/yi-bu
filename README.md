# 易卜 · 六爻占卜

一个离线可用的八卦占卜 App：铜钱摇卦、时间起卦、数字起卦、手动排卦，按传统变占法自动解卦。

**不联网、不申请任何权限、无广告、无追踪。** 六十四卦与三百八十四爻的经文全部内置在安装包里。

## 下载

| 产物 | 说明 |
|---|---|
| `dist/易卜.apk` | 安卓安装包，56 KB，Android 5.0+ |
| `dist/易卜.html` | 单文件网页版，浏览器直接打开即可 |

## 功能

**四种起卦**

- 铜钱摇卦：三枚铜钱摇六次，背为阳、字为阴；6 老阴、7 少阳、8 少阴、9 老阳，动爻自动标 ○ ×
- 时间起卦：公历年月日取上下卦，加时辰取动爻
- 数字起卦：随心两个数（可另指定动爻数），除八取余定卦、除六取余定爻
- 手动排卦：逐爻点选少阳 / 老阳 / 少阴 / 老阴

**解卦**

- 本卦、变卦、互卦三卦并列，六爻对照，动爻高亮
- 断爻用朱子《易学启蒙》变占法：
  - 六爻不动 → 本卦卦辞
  - 一爻动 → 本卦该动爻爻辞
  - 二爻动 → 两动爻爻辞，以上爻为主
  - 三爻动 → 本卦、变卦卦辞合断，本卦为主
  - 四爻动 → 变卦中二不变爻，以下爻为主
  - 五爻动 → 变卦不变爻
  - 六爻全动 → 乾用九、坤用六，余卦取变卦卦辞
- 吉凶按辞气判：扫断辞中的「元吉 / 无咎 / 悔亡」与「凶 / 吝 / 厉 / 灾」加权，给出大吉到凶五档，并把判据写出来
- 分占事业、情感、财运、身体：用上下卦的象、德、身体取象推演
- 卦典可查全 64 卦，占卦可存记录、一键复制

## 目录

```
data/            卦爻辞数据源（p1–p4.py，按卦序分段）
build.py         合并校验 → gua.json（检查卦数、爻数、卦象唯一性）
template.html    网页应用模板（含全部样式与逻辑）
build_html.py    注入数据 → 易卜.html，并做 JS 语法与变卦逻辑自检
android/         原生壳工程（WebView）
gen_icon.py      零依赖生成应用图标 PNG
add_dex.py       把 classes.dex 并入 APK
build_apk.sh     一键打包 APK
dist/            发布产物
```

## 构建

网页版：

```bash
python3 build.py        # 校验卦数据
python3 build_html.py   # 生成 易卜.html
```

APK（不用 gradle，aapt + javac + r8/d8 + zipalign + apksigner 手工链路）：

```bash
bash setup_dev.sh       # 安装 JDK、aapt、apksigner、zipalign，下载 android.jar 与 r8.jar
bash build_apk.sh       # 产出 易卜.apk
```
